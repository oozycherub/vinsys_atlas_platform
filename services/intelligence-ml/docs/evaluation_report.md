# Attrition model: evaluation report

> **Synthetic data.** Generated by `eval/evaluate.py` from `intelligence_ml.synthetic`. These
> numbers show the method and the gates working; they say nothing about real HR data. Each
> tenant's own metrics are stored with its model and shown to HRBPs (`GET /v1/attrition/model`).

## Data and split

- 18,000 employee-month snapshots, voluntary-exit rate 22.0%.
- Time-based split: train 10,800, calibration 3,600, test 3,600 (oldest to newest).

## Feature governance

- Features used: `tenure_months`, `months_since_promotion`, `months_in_role`, `compa_ratio`, `manager_changed_6m`, `team_attrition_6m`, `peer_exits_6m`, `skill_gap`, `skill_gap_trend`, `internal_applications_6m`, `marketplace_rejections_6m`, `engagement_delta`, `overtime_hours_4w`.

- Proxies dropped in this run (MI > 0.1 bit): none.
- Proxy check on a dataset with a planted proxy: `engagement_delta` dropped (MI 0.80 bit with gender).
